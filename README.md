# Simple Calculator in C

A beginner-friendly calculator program written in C.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero error handling
- Operator validation

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code

## How to Run
1. Compile the program:
   `gcc calculator.c -o calculator`
2. Run the program:
   `.\calculator.exe`

## Learning Goals
This project helped me practice:
- Variables and data types
- User input using `scanf()`
- `switch` statements
- Conditional statements (`if-else`)
- Basic arithmetic operations

Created as part of my C programming learning journey.
